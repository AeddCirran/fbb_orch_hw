# ДЗ 3

Оба сервера и клиет были успешно написаны.

Но при тестировании было осознано, что при каждом обращении клиента к серверу клиент вынужден каждый раз угадывать одинаковое число. Чтобы внести элемент разнообразия было решено использовать не простую генерацию псевдослучайных чисел, а `np.random.default_rng`. Эта версия серверов позволяет клиенту сыграть несколько разных игр до первого проигрыша и возобновлять прерванную игру.
